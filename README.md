# Outer Nonsense

A Sci-fi Space Universe

## What is this?
This is a universe that I'm creating. I am an extreme fan of the game [Sigma Star Saga](https://en.wikipedia.org/wiki/Sigma_Star_Saga), and since I know it might (putting the vibes out there) not ever get a sequel, I decided to start working on a spiritual successor. 
Every so often, I'll update the bible with more stuff as I come up with it. Eventually a game will be made in this universe using [TGL](https://github.com/CaptainSly/TheGildedLibrary). 

The intended rating for this universe and setting is Mature. Dark Absurdist Comedy mixed with Tragic and Cosmic Horror. 

The [Universe Bible](Universe%20Bible.md) is where the universe is being created. The way it's written, I write base truths, then fix contradictions as I need, or meld them into making sense later on in the long run. Also the way it's written is also a bit... crude, shall we say. Any thought I have goes directly into the bible through text to speech. I fix formatting errors and spelling mistakes, but other than that I leave it raw. I think I'll end up deriving a Compendium, Codex or whatever that outlines a lot of the bible, but through written word instead of just bullet points. I'm not sure when that'll happen.
